# Contexto

As publicações oficiais contêm texto original que expressa a forma completa da comunicação institucional. Esse texto pode ser relevante tanto para a auditoria quanto para interpretações futuras.

# Problema

Se o texto bruto fosse descartado após a extração inicial, o sistema perderia a prova documental original e ficaria dependente de interpretações parciais.

# Decisão

O texto bruto não é descartado. Ele permanece associado à publicação e é preservado como parte central do domínio.

# Consequências

O sistema ganha maior fidelidade documental e maior capacidade de reinterpretação sem perda de origem.
