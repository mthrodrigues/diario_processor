# Contexto

O sistema trabalha com dois tipos de valor distintos: o texto documental original e as interpretações estruturadas que dele são derivadas.

# Problema

Se esses dois níveis fossem confundidos, a base perderia clareza sobre o que é prova documental e o que é inferência construída sobre essa prova.

# Decisão

Foi adotada a separação entre evidência documental e conhecimento derivado.

# Consequências

O modelo mantém uma distinção explícita entre o que foi publicado e o que foi inferido, reforçando rastreabilidade e qualidade semântica.
