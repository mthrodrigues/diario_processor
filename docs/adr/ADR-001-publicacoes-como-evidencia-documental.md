# Contexto

O domínio é composto por Diários Oficiais que reúnem diversas publicações independentes. Cada uma dessas ocorrências carrega valor documental próprio e precisa ser tratada como unidade autônoma de referência.

# Problema

Se o sistema tratasse apenas a interpretação administrativa como ponto central, perderia a origem documental das informações. Isso tornaria mais difícil preservar a prova de cada fato e comprometeria a rastreabilidade.

# Decisão

As publicações passaram a ser tratadas como evidência documental primária. Cada publicação é preservada como unidade independente, e as interpretações subsequentes se relacionam a ela.

# Consequências

O sistema mantém uma base documental robusta e rastreável. A interpretação ganha confiança porque sempre pode ser vinculada a uma publicação concreta.
