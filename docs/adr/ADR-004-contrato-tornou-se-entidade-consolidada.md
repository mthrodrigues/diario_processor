# Contexto

Assim como os processos, os contratos aparecem em múltiplas publicações e precisam ser reconhecidos como entidades administrativas recorrentes.

# Problema

Manter o contrato apenas como valor textual disperso tornava difícil identificar a ocorrência de um mesmo instrumento ao longo do tempo.

# Decisão

O contrato passou a ser tratado como uma entidade consolidada, com identidade própria e catálogo próprio.

# Consequências

O sistema passou a representar os contratos como objetos administrativos estáveis, facilitando a consolidação e a consulta estruturada.
