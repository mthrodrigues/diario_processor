# Contexto

As informações extraídas de cada publicação precisam ser agrupadas para formar uma visão mais ampla do domínio.

# Problema

Se a consolidação fosse feita apenas no momento da extração, a estrutura do conhecimento ficaria dependente de cada processamento local e seria mais difícil manter consistência.

# Decisão

A consolidação foi definida como uma etapa independente da extração, realizada após a ingestão das publicações.

# Consequências

O sistema consegue construir catálogos derivados com maior consistência e sem depender diretamente do fluxo inicial de interpretação.
