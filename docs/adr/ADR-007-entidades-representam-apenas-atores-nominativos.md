# Contexto

O sistema precisa representar diferentes tipos de conceitos, mas nem todos devem ser tratados como entidades equivalentes.

# Problema

Se tudo fosse tratado como entidade, perder-se-ia a distinção entre atores nominativos e objetos administrativos.

# Decisão

As entidades representam apenas atores nominativos, como pessoas, empresas e órgãos.

# Consequências

O modelo se torna mais claro, separando o papel dos agentes institucionais do papel dos objetos administrativos como processos e contratos.
